# Oblako

Безплатно приложение за прогноза на времето: текущо време, почасова и дневна прогноза, вероятност за валежи, UV индекс, качество на въздуха и полен, изгрев, залез и лунна фаза, интерактивна карта и графики. Единиците за температура, вятър (m/s, km/h, mph), налягане и видимост се избират в менюто. Работи на български и английски, в светла и тъмна тема, и може да се инсталира като приложение (PWA), показвайки последната прогноза без интернет.

Сайт: https://oblako17.online

## Данни

Приложението **не изисква API ключове**.

| За какво                   | Услуга                                                                                                |
| -------------------------- | ----------------------------------------------------------------------------------------------------- |
| Прогноза и търсене на град | [Open-Meteo](https://open-meteo.com/)                                                                 |
| Резервна прогноза          | [MET Norway](https://api.met.no/) Locationforecast (CC BY 4.0)                                        |
| Качество на въздуха, полен | [Open-Meteo Air Quality](https://open-meteo.com/en/docs/air-quality-api) (CAMS; полен само за Европа) |
| Име и област по координати | [BigDataCloud](https://www.bigdatacloud.com/) (reverse geocoding, без ключ)                           |
| Официални предупреждения   | [MeteoAlarm](https://meteoalarm.org/) / НИМХ, само България (CC BY 4.0)                               |
| Карта                      | OpenStreetMap, Esri и OpenTopoMap (плочки)                                                            |

Open-Meteo е безплатна за некомерсиална употреба и изисква посочване на източника (във футъра е). За комерсиална употреба вижте условията им.

Само файловете на доставчиците ([openmeteo.js](src/services/weather/openmeteo.js) и [metno.js](src/services/weather/metno.js)) знаят за конкретните API-та. Останалото приложение ползва единния модел от [src/services/weather/index.js](src/services/weather/index.js), описан с JSDoc типове.

### Резервен доставчик

Ако прогнозата от Open-Meteo върне HTTP 429 или 5xx, тя се взима от MET Norway. Ограничения на резервния режим:

- Заменя само прогнозата. Търсенето на град остава в Open-Meteo, а за качеството на въздуха няма резерва.
- Вероятност за валежи има само за Северна Европа, а видимост няма никъде; приложението показва „—“ или скрива реда.
- UV индексът е за ясно небе, т.е. при облачност е завишен.
- Дните са около 10 вместо 14; почасовата прогноза е за около 2-3 дни. Днешните стойности обхващат само оставащата част от деня.

[Условията на MET Norway](https://api.met.no/doc/TermsOfService) допускат директни заявки от браузъра само при малък трафик. При по-голям трафик трябва кеширащ прокси сървър.

## Слънце и Луна

Изгревът, залезът, продължителността на деня и лунната фаза се изчисляват в браузъра от координатите на мястото и текущия момент, без заявки ([src/services/astronomy/index.js](src/services/astronomy/index.js)).

## Предупреждения за времето

Приложението показва предупреждения на началната страница (`WeatherAlerts`):

- **Официални (само България):** [api/alerts.js](api/alerts.js) е Vercel Function, която взима feed-а на MeteoAlarm и връща само активните предупреждения (ниво жълто и нагоре). Нужна е, защото feed-ът няма CORS заглавия и браузърът не може да го чете директно. Функцията няма параметри и не получава данни от потребителя; отговорът се кешира в CDN-а 5 минути. Областта на потребителя (ISO код от BigDataCloud, напр. `BG-22`) се свързва с NUTS3 кода на MeteoAlarm чрез таблицата в [src/services/alerts/regions.js](src/services/alerts/regions.js).
- **Собствени (за всяко място):** [src/services/alerts/thresholds.js](src/services/alerts/thresholds.js) изчислява от прогнозата за следващите 48 часа вятър, гръмотевици, сняг и поледица, проливен дъжд, жега и студ. Праговете са в `THRESHOLDS` на едно място. Ако има официално предупреждение от същия вид със същото или по-високо ниво, собственото се скрива.

В `npm run dev` няма `/api`, затова там се виждат само собствените предупреждения. За да пробвате и функцията локално, ползвайте `vercel dev` (не е зависимост на проекта).

## Изисквания

Node.js `^20.19.0` или `>=22.12.0` (изискване на Vite 7).

## Команди

```bash
npm install            # зависимости
npm run dev            # dev сървър (Vite, http://localhost:5173)
npm run build          # production билд в dist/
npm run preview        # локален преглед на билда от dist/

npm run lint           # ESLint
npm run lint:fix       # ESLint с автоматични поправки
npm run format         # Prettier: форматира всичко
npm run format:check   # Prettier: само проверка (без промени)
```

Service worker-ът (офлайн режим) се генерира при `npm run build`. В `npm run dev` не е активен, затова офлайн режимът се проверява с `npm run build && npm run preview`.

## Структура

```
src/
  pages/            страниците (начало, прогноза, валежи, UV, съвети, правни текстове)
  components/       компоненти; всеки със свой CSS модул (*.module.css)
  hooks/            useWeather (място, геолокация, кеш), useAlerts, заявки, useSeo
  services/weather/ данни за времето: единен модел + доставчик (Open-Meteo)
  services/astronomy/ Слънце и Луна, изчислени локално
  services/alerts/  предупреждения: прагове, области на България, клиент към /api/alerts
  utils/            локация, localStorage, анализи
  translations.js   всички текстове (bg / en)
api/                Vercel Function за официалните предупреждения (MeteoAlarm)
public/             статични файлове, манифест, икони, снимки на градове
vercel.json         SPA rewrite и security заглавия (CSP и др.)
```

## Деплой

Сайтът е статичен, с една изключка: Vercel сервира `dist/` (`npm run build`) и функцията в `api/`. [vercel.json](vercel.json) задава пренасочването към `index.html` и заглавията за сигурност, включително Content Security Policy. Нов външен адрес (API, CDN, шрифт) трябва да се добави в CSP, иначе браузърът ще го блокира.

## Поверителност

- Google Analytics се зарежда само след съгласие („Приемам всички“), с Google Consent Mode; без съгласие към Google не се изпраща нищо.
- Местоположението се иска от браузъра и се изпраща само към Open-Meteo и BigDataCloud. Oblako няма база данни и не го съхранява; функцията за предупреждения не получава местоположение.
- За работа без интернет на устройството се пазят кеш на приложението и последното място (закръглено до около 1 км).

Подробности са в страниците „Правила за поверителност“ и „Политика за бисквитки“ ([src/pages/Privacy.jsx](src/pages/Privacy.jsx), [src/pages/Cookies.jsx](src/pages/Cookies.jsx)).
